# Detailed Map UI and Route Geometry Plan

## Goals
- Replace schematic point-to-point lines with multi-segment 2D routes.
- Add realistic geography: rivers, lakes, mountains, forests, plains, and contour bands.
- Make the map readable and game-like.

## Implementation steps
1. Redesign the map canvas with layered terrain.
2. Add contour/topography bands and a richer legend.
3. Render each route as 2 or 3 connected segments.
4. Style active/inactive routes and terrain crossings.
5. Improve node markers and labels.
